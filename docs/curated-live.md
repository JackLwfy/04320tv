# 精选直播频道与验证记录

## 维护方式

- 来源：[iptv-org/iptv](https://github.com/iptv-org/iptv) / [streams API](https://iptv-org.github.io/api/streams.json)。
- 清单：`public/live/curated.m3u`；仅人工维护，不全量同步上游。
- 默认增加“04320 精选直播”源，保留部署者和访客自行配置的源；同 URL 已在环境配置中出现时尊重原来的 enabled 状态。
- `/admin` → 功能设置 → “精选直播频道”控制内置源，“直播栏目”控制所有直播。保存并部署、访客刷新后生效。
- 清单从本仓库 main 的 GitHub Raw 获取，服务端沿用 10 分钟缓存。需保持仓库公开且服务器能够访问 GitHub Raw；缓存过期后网络故障可能导致列表暂时不可用。
- 精选源的开关不移除用户手工添加的同地址源；若手工重复添加，需另行停用该自定义源。
