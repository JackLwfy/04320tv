# 日报／周报固定海报

04320.com 的邮件海报保存在现有持久数据库的独立 `newsletter_images` 表，避免云函数临时磁盘和第三方代理失效。`/newsletter-images/<SHA256>.<jpg|png|webp>` 匿名读取固定字节，按内容哈希命名，不覆盖、不随推荐历史90天清理；成功响应缓存一年，错误不缓存。

邮件服务器下载并解码校验图片，限定HTTPS公网、禁止跳转、最多4MB和4000万像素；仅将本期入选海报提交到 `POST /api/newsletter/images`。上传需要独立 `NEWSLETTER_IMAGE_SECRET` 的HMAC签名（固定用途前缀、秒级时间、正文SHA256，五分钟窗口）。重放相同内容是幂等保存，接口不接受任意源URL，不向浏览器公开密钥。读取路径只允许哈希文件名，输出安全MIME和nosniff。

部署先对统计库做备份及恢复验证，再运行 `scripts/analytics/newsletter-images.sql` 并同步 `maintenance.py` 的表白名单。`node scripts/analytics/edgeone-ops.cjs image-configure` 设置独立服务端密钥，在仓库外私有目录生成邮件端配置；配置复制到邮件系统storage且限制文件权限。然后部署网站。备份包括海报字节；海报不属于统计明细清理范围。回滚代码时保留表和已发邮件引用的图片；维护脚本继续包含该表。

邮件系统将来源URL映射到固定图片地址以复用已保存版本。旧邮件内容无法追溯修改；片源更换地址产生新的内容快照。用户提供的图片应具备使用授权；此功能不改变影片播放链接。

验证：签名、大小/格式与哈希限制、内容幂等、固定字节读取、ETag与错误不缓存有自动化测试；收件客户端显示不属于服务器图片保存验证。
