# 04320 数据统计

网站与后台仍在 EdgeOne；Node 云函数通过校验证书的 TLS 连接独立 MariaDB 库。数据库服务器没有新增 HTTP 服务。

## 数据和页面

后台「数据统计」提供概览、访问分析、推广链接、搜索需求、内容热度、播放质量、订阅转化、采集运行。支持北京时间日期、适用的片源/播放类型/设备/浏览器筛选、分页及当前页 CSV；推广链接导出当前筛选的全部链接（最多10000条）。CSV 时长使用毫秒，公式前缀已转义。

- 浏览器匿名标识保存在签名 HttpOnly Cookie 中，数据库只存 HMAC 后的标识。测试访客使用独立哈希域，所有验收数据标记 `is_test=1`。
- 「访问分析」提供全国34省级区域分布、PV/设备UV/去重IP切换、IP明细与CSV。`edge-functions/api/analytics/collect.js` 从平台原生 `request.eo` 读取客户端IP和省份，忽略浏览器同名字段/头；将60秒有效、绑定完整请求体的HMAC证明传给本站 `/api/analytics/ingest` 云函数，校验后直接TLS写库。Next.js由OpenNext适配，不使用平台通用middleware。参见[EdgeOne Request文档](https://edgeone.ai/document/52690)。IPv6规范化后去重，IPv4映射IPv6与IPv4统一计数。本地Next dev使用回环IP及未知地区，生产不允许无签名网络信息。
- IP/省份仅随访问事实保存90天，完整IP只在受保护管理员报表中提供。地域基于IP网络出口，代理、VPN、移动网络与定位库可能造成偏差。省份不明、归属未知及境外单列，旧记录不回填；跨省设备/IP不能将各省去重数相加当成全国去重数。地域数据遵循日期/设备/浏览器筛选，不受分页限制。
- 城市、ASN也从EdgeOne原生上下文读取并随请求体签名校验。点击地图、排行或省份表后，IP明细、城市统计和运营商表按省份筛选，并跳转到IP明细；地图、全国卡片和趋势保留全国口径。三张明细表仍支持日期/设备/浏览器、分页和CSV，导出明确标识所选省份。
- IP明细的首次/最后访问时间在页面与CSV中均为北京时间（UTC+08:00）；数据库原始时间仍存UTC。
- IP明细在当前日期/设备/浏览器/省份等筛选范围内按IP一行展示：各归属字段取最近一次非空值（未知和ASN 0不覆盖已知值），PV汇总、设备UV按visitor_id去重、访问次数按session_id去重。相同事件时间按接收时间、事件ID排序，页面、分页总数与CSV共用该口径。各归属字段可能来自不同时间；原始事件不改写，历史仍按90天规则保留。城市、运营商和省份分布继续按原始事件归属统计，因此与IP表展示的最近归属不必相同。
- 城市名使用平台原始值，可能为英文；未识别城市/ASN保留未知。运营商按IP所属ASN的网络组织识别，不等同于实际开户宽带商；离线快照包含CN/HK/MO/TW组织及识别到的中国运营商网络，其它网络保留明确AS编号。`analytics-operators.json`记录RIPE源地址、快照日期和SHA256，不向第三方发送访客IP。组织/ASN转让后需刷新快照；使用完整[RIPE ASN文件](https://ftp.ripe.net/ripe/asnames/asn.txt)执行单行 `node scripts/analytics/update-operators.cjs <下载的asn.txt路径>`，脚本校验完整源行数和主要运营商映射再生成。城市/运营商的UV、IP也不可跨组直接相加。
- 访问次数以连续 30 分钟无活动划分。UV 是区间内浏览器去重数，不代表真实人数。
- 搜索按逻辑 searchId 去重；正常无结果、部分失败、全部失败分开。点击/起播转化以范围内的搜索为基准，并核对匿名设备。显式重复搜索同一个词会产生新逻辑搜索；命中缓存时不伪造新的片源网络耗时样本。
- 每个播放尝试保存最新累计快照。递增序号、所有累计值不回退、归属匿名设备一致才允许更新（保留最初会话，允许暂停后新访问继续累计）。观看时长排除暂停、跳转和缓冲，后台播放是其中的子集。
- 首帧优先使用 video frame callback，旧浏览器采用进度前进；45 秒未起播记超时。用户提前离开单独统计。有效观看为至少30秒，短视频需完整播放。
- 观看数据按尝试开始日归属。不同片源同名内容不自动合并。来源 key 在浏览器发送前哈希；不保存带令牌媒体地址和邮箱。
- 推荐记录可见曝光、点击以及关联搜索后的起播。订阅的 accepted 仅表示接口受理；确认、退订、发信、送达需外部回传，当前不伪装为零。
- 浏览器行为是可漏报、可伪造的观测，不等于服务端探测、邮件送达或真实人数。

## 资源和留存

每个云函数实例最多2个数据库连接，等待队列最多4项；数据库用户总连接上限12。批次最多20个事件、请求体32KiB；签名会话、同源限制、字段边界和数据库限流同时生效。明细查询限制4秒。数据库故障时采集返回503，前台有限重试且不阻止播放，后台显示不可用而不是假零。

结构化事实、播放、搜索源结果保留90个完整北京时间日期；短期回执2天；日汇总和匿名访客最多400天。未额外保存原始JSON心跳或完整错误日志，因此采用统一90天结构化明细留存。超过90天只提供无细分的日汇总概览，不能跨日相加生成区间UV，也不平均每日P95。

`maintenance.py` 仅允许固定服务器和独立库：5分钟幂等汇总、每日分批清理、每日备份。任务互斥，状态写入 `analytics_jobs`。备份仅短暂锁本统计库，生成一致快照并真实恢复到随机临时库，核对12张表行数，删除临时库后保留最近7份成功备份。服务器备份/清理在服务器本地时间03:17/03:37；服务器采用欧洲时区，会随夏令时变化。

`pull-backup.ps1` 经 Tailscale 拉取已恢复验证的备份到仓库外私有目录，逐文件核对 SHA256，保留7份。Windows 任务每日北京时间11:00运行，错过后启动时补跑；需要这台电脑开机、用户登录及 Tailscale 可用。状态在私有目录 `offsite-backup-status.txt`。长期无人值守应改为常在线异地存储。

## 配置与操作

EdgeOne 仅服务器环境变量：`ANALYTICS_DB_HOST`、`ANALYTICS_DB_PORT`、`ANALYTICS_DB_NAME`、`ANALYTICS_DB_USER`、`ANALYTICS_DB_PASSWORD`、`ANALYTICS_DB_TLS_NAME`、`ANALYTICS_DB_CA`、`ANALYTICS_INGEST_SECRET`、`ANALYTICS_ENABLED`。CA 在 EdgeOne 中以字面 `\n` 保存，应用解码；不要在平台环境变量中写真实多行。TLS证书名称与连接IP独立校验。所有统计连接会话设置UTC，不改变服务器全局时区。

初始化脚本必须先核验服务器身份；`create` 通过 aaPanel 建独立库和最小权限用户，`tls`/`activate`涉及数据库服务重启，仅首次部署需要。`schema` 只为指定库执行幂等建表。禁止重跑首次初始化去覆盖已有数据库或证书。

已有库升级IP/地域功能先执行已验证恢复的备份，再运行 `migrate-geography.py`（同目录需要维护脚本及SQL）；仅增加字段，不删除旧事实。线上部署成功并验证平台归属透传后，将 `analytics_meta.geography_started_at` 从NULL设置为当前UTC，保留首次启用时间。新库schema也包含这些字段。代码回滚可保留新增字段，旧版照常运行。

手工覆盖本次增量包时，须删除旧文件 `src/app/api/analytics/collect/route.ts`；公开采集URL由原生边缘函数接管。Git部署自动处理该删除。部署验收通过后执行 `migrate-geography.py --activate`，幂等记录地域启用时间。

升级城市/运营商统计先备份并验证恢复，再运行 `migrate-network-details.py`（同目录带SQL和维护脚本）。这是schema v3的加字段迁移，不回填旧数据；原生边缘函数与云函数上线验收通过后运行 `migrate-network-details.py --activate` 记录首次启用时间。省份旧迁移不会降低已有schema版本。

在项目根目录运行以下单行命令。配置、API密钥及备份均在仓库外/忽略文件中，不随代码和ZIP发布。

- 部署状态：`node scripts/analytics/edgeone-ops.cjs status`
- 线上 TLS 健康检查：`node scripts/analytics/edgeone-ops.cjs health`
- 隔离线上验收：`node scripts/analytics/smoke.cjs https://04320.com`
- 有限4并发、400事件验收：`node scripts/analytics/smoke.cjs https://04320.com --load`
- 全仓检查：`npm test; npm run lint; npm run typecheck; npm run build`
- 实库集成测试（本地已配置隔离环境）：`$env:ANALYTICS_INTEGRATION='true'; node --env-file=.env.local node_modules/vitest/vitest.mjs run src/lib/analytics-integration.test.ts; Remove-Item Env:ANALYTICS_INTEGRATION`

`smoke.cjs` 使用管理员权限请求隔离测试令牌，检查授权、来源、校验、去重、7视图和CSV，结束时仅删除本次访客测试记录。普通用户不能启用测试模式。`ANALYTICS_TEST_MODE` 只用于本地验收，禁止设置到线上。

## 推广链接（schema v4）

「数据统计 → 推广链接」按活动、渠道、投放位置和素材版本管理独立链接。生成同源落地路径加 `promo=8位短码`，保留页面原参数和片段；后台、接口及站外目标被拒绝。投放属性固定，仅允许改名称、备注和归档状态。复制创建会生成新编号；归档后原链接仍可访问和归因，历史不删除。

- 认证前捕获入口，认证后才上报。每次推广访问有独立编号；普通刷新复用编号，入库回执和访问主键双重去重。站内导航保留来源，新的推广入口切换后续行为，连续30分钟无活动后结束。来源在事件入队时冻结；播放按尝试开始时的来源固定，已开始的播放心跳不会转入另一个渠道，也不会复活已过期的全局来源。
- 服务端核对链接存在、访问所属匿名设备、测试域、入口时间和空闲窗口。无效或伪造的推广归因会被清空，普通统计事实仍保留。地区只使用已有平台签名网络信息。推广访问表不另存IP。
- 到站次数以推广访问去重，设备按匿名浏览器标识去重，活动汇总重新去重，不能直接相加各链接UV。新设备为400天可识别记录中首次出现。页面浏览只计 `page_view`，成功起播要求首帧，受理设备只表示订阅接口受理，不表示邮件送达。推广有效观看为**同一次推广访问累计60秒前台实际播放**；与原全站播放质量的30秒指标口径分别标注。
- 日期范围选取**到站日**对应的推广访问，再统计这些访问的后续行为；跨午夜行为归到站日。趋势按到站日分组。设备/浏览器以到站时维度筛选；分子分母属于相同访问集合。详情提供搜索和内容前50项、地区前100项；同名影片按片源及内容编号区分。完整时长使用最新去重播放快照，不累加心跳。
- 推广访问、事件及播放明细均遵守90个完整北京时间日期留存，推广链接定义保留。无到站设备时转化率为不可用；统计故障显示错误，不能当作零。旧 `utm_source` 继续在原访问来源报表中显示，未生成独立推广编号的历史访问不自动认领。转发链接仍归原链接；浏览器拦截、跨设备和清理存储会影响观测。

已有库升级前先用服务器现有维护脚本执行 `backup`，确认实际恢复成功。将 `migrate-promotions.py`、`migrate-promotions.sql` 传入 `/root/04320-analytics/`，使用现有 `/www/server/panel/pyenv/bin/python3` 执行迁移（要求一小时内的已恢复验证备份）。迁移只增加两张表、归因字段和索引，schema升至4，不回填旧事实、不重启数据库。随后安装新版 `maintenance.py`（备份表清单12张，推广访问按90天清理），再验证一次备份恢复。代码回滚可保留新增表和字段；维护脚本继续使用12表版本。

隔离推广验收单行命令：`node scripts/analytics/smoke-promotions.cjs https://04320.com`。只建立唯一活动名称的临时链接及 `is_test=1` 访客事实，不实际订阅或发信；结束时仅删除本次验收创建的链接和隔离事实。真实数据库集成测试为 `src/lib/analytics-promotions-integration.test.ts`，需显式设置 `ANALYTICS_INTEGRATION=true`，并使用已迁移的独立统计库。

schema v5 将公开参数缩短为8位URL安全随机码（`A-Z`、`a-z`、数字、`_`、`-`），区分大小写；数据库唯一约束防碰撞，生成最多尝试3次。内部UUID、访问编号和历史归因不改，原 `promo=UUID` 继续有效。既有链接由迁移补发固定短码，后台复制统一返回短参数，无需重建链接。

升级短码前完成一次已恢复验证的备份，再将 `migrate-promotion-codes.py` 和 `.sql` 传入同一维护目录，使用现有Python执行迁移；回填只更新空短码，幂等重跑不会改变已分配短码。新增短码列允许NULL以兼容旧版本代码；上线后重跑迁移确认发布期间由旧实例创建的链接也已补齐，再备份恢复核验。旧代码回滚仍能使用UUID，短码链接需要保留支持schema v5的采集代码。

## 停用与回滚

紧急停采可在独立统计库执行 `UPDATE analytics_meta SET enabled=0 WHERE id=1`，立即阻止新事实入库；恢复改回1。前台搜索播放不依赖统计成功。

永久停采用 `node scripts/analytics/edgeone-ops.cjs disable` 然后 `node scripts/analytics/edgeone-ops.cjs deploy`，等待成功；恢复用 `enable` 再部署。环境变量变更必须重新部署才会进入云函数。

代码回滚使用新提交恢复需要的版本，再推送部署，不强推、不删除统计库。原有 EdgeOne 环境变量、aaPanel数据库、数据库服务配置均已在私有目录备份。回滚 TLS 配置会影响这个统计用户的连接，只有确认其它业务状态和服务重启窗口后才操作；常规停采不需要恢复全局数据库配置。

统计从启用时开始，没有可追溯的历史访问数据。已有依赖的安全审计不是本统计功能验收的替代品；本次未做无关框架大版本升级。
